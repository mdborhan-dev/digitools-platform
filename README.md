# DigiTools Platform

A digital marketplace for browsing and selecting AI and professional digital tools.

🔗 **Live Demo:** [digitools-platform-pha06.netlify.app](https://digitools-platform-pha06.netlify.app/)

---

## 📌 About The Project

**DigiTools Platform** is a React-based web application where users can browse a collection of digital and AI tools, add them to a cart, and manage their selections — all from a clean and responsive interface.

This project was built as part of a web development course to practice React fundamentals, component-based design, and state management.

---

## 🛠️ Built With

- React.js
- Tailwind CSS
- daisyUI
- JavaScript (ES6+)
- react-toastify¹
- 🪝 React Hooks — `useState`

---

## ✨ Features

- **Browse Tools** -- View a list of digital and AI tools on the main page
- **Cart Functionality** -- Add item to carts & remove them as tou wan , also checkout
- **Toast Notification** -- See Notification on the top right of screen when you Add/Remove item from cart and checkout
- **Prevent Duplicates** -- Add to cart button doesn't work after selecting once.
- **Responsive layout** -- Responsive layout for small medium and large devices

## 🚀 Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```

**2. Install dependencies**

```bash
npm install
```

**3. Start the development server**

```bash
npm run dev
```

**4. Open in your browser**

```
http://localhost:5173
```
